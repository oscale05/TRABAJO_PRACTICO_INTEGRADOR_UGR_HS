# Port Log — Trabajo Práctico Integrador

**Sprint actual: Sprint 2**

## Objetivo
Aplicar conocimientos de tratamiento de imágenes y programación limpia sobre el contexto del sistema portuario.

## Introducción y contexto
El Puerto Fluvial de Rosario es uno de los complejos portuarios más importantes de
América del Sur y el principal punto de exportación de granos y derivados de la
Argentina. El sistema de registro de movimientos portuarios acumuló inconsistencias
de formato en el sistema heredado de los años '90.

En el Sprint 2 se incorpora el análisis de evidencia fotográfica de las infracciones:
imágenes de buques (grupos `plates` y `completes`), preprocesamiento con OpenCV,
extracción de matrículas con OCR y cruce con el dataset tabular depurado en el Sprint 1.
